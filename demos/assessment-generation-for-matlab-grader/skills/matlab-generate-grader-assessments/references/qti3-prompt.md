# QTI 3 companion export prompt

When enabled in the course profile, create a QTI 3 companion package that preserves the Script, Function, Class Definition, Class Inheritance, Object Usage, or Class Methods description, template, solution, optional run/call block, referenced-file metadata, and `assessments.md` content as metadata for review and later import.

Preserve localized artifact content exactly as generated. Do not translate the description, code comments, assessment names, or optional feedback during QTI packaging.

Keep native MATLAB Grader artifacts authoritative. State neither explicitly nor implicitly that a generic QTI runtime can execute MATLAB code or MATLAB Grader assessments. Use package-relative item paths and well-formed XML.
